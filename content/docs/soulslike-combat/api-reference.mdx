## Base Classes

### AEnemyControllerBase

```cpp
// Get components
UMovementEvaluatorComponent* GetMovementEvaluator();
UThreatDetectionComponent* GetThreatDetection();
UActionEvaluationComponent* GetActionEvaluation();
```

---

### AEnemyCharacterBase

```cpp
// Get ASC
UAbilitySystemComponent* GetAbilitySystemComponent() const override;

// Equip weapon
void SpawnWeapon(TSubClass<ASECWeaponBase> WeaponToSpawn);
```

---

### ASECWeaponBase

```cpp
// Equip/unequip
void OnEquipped(FSECEquipContext Context);
void Unequip(FSECUnequipContext Context);
FName GetDefaultAttachSocket();
FTransform GetDefaultAttachOffset();

// Auto-behavior:
// - On Equip: Attaches, registers traces, sends tag event, links animation layer
// - On Unequip: Detaches, unregisters, sends tag event
```

## Roadmap

### 2026 Q1

**Player Combat Component**
- Combat system for player
- Input handling and combo system

**Example Player Character**
- Pre-configured third-person/first-person character
- Working attacks, dodges, blocks
- Demonstration of player-enemy interaction

### 2026 Q1-Q2

**Multiplayer Support**
- Replication for server-authoritative combat
- Client prediction for responsive feel
- Authority handling for damage and abilities
- Networked movement and actions

### 2026 Q3

"Experimental"
**Group Tactics System**
- Coordinated multi-enemy attacks, extra token layer if needed
- Formation movement
- Separation of Action Behaviors (Attack, Buff, Debuff, etc.)
